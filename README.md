# tx.taxi Explorer Source Downloads

This repository distributes reviewed source archives for the BTC/XMR tx.taxi
explorer, a fork of [mempool](https://github.com/mempool/mempool).

Download archives from [Releases](https://github.com/tx-taxi/explorer-source/releases).
Each release identifies the full source revision, includes a SHA-256 checksum,
and contains the application source, dependency lockfiles, assets, license notices,
and build instructions. Prereleases identify staged candidates, not public rollouts.

The development repository and its Git history are private. These archives do not
contain runtime credentials, database contents, or private operational notes.
Licensing terms and upstream notices are retained inside each archive in `LICENSE`
and `COPYING.md`. A source download does not include third-party hosting services
or grant rights to upstream trademarks.

After extraction, start with `BUILD-SOURCE.md` and `SOURCE-MANIFEST.json`.
Archived deployment recipes are examples; supply your own endpoints and credentials.
Release notes state the tested build and any limitations.

The separate Ethereum explorer fork is available at
[tx-taxi/ethereum-explorer](https://github.com/tx-taxi/ethereum-explorer).
